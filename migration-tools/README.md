# Estuary Migration Tools

Tools for migrating data pipelines to Estuary.

Each tool lives in its own directory with its own README, which documents what
the tool does, the API calls it makes, and the permissions it needs.

| Tool | Purpose |
|---|---|
| [dms](dms/) | Read-only inventory of AWS DMS replication workloads, for migration sizing |

All tools are read-only against the source vendor's APIs.
